# Mood Tracker

매일 저녁 5분 안에 감정과 컨텍스트를 기록하는 모바일 PWA.
"감정기복이 진짜 큰가?"를 데이터로 검증하려고 만들었다.

앱 주소: https://nelly59290-source.github.io/mood-tracker/

---

## 설치 (iPhone)

1. 사파리로 위 주소 열기
2. 공유 버튼 ⬆️ → **홈 화면에 추가**
3. **반드시 홈화면 아이콘으로만 열 것**

iOS는 홈화면 앱과 사파리의 저장소를 분리한다. 사파리에서 열면 기록이 따로 쌓이고,
푸시 알림도 홈화면 앱에서만 동작한다.

---

## 세 가지 기능

### 1. 기록

앱을 열면 항상 빈 폼으로 시작한다. 슬라이더 두 개(기분/각성도)만 움직이고 저장해도 되고,
수면·운동·업무강도·카페인 등을 채워도 된다. 30~60초면 끝나도록 만들었다.

지난 날짜를 고치거나 빠뜨린 날을 채우려면 **캘린더 탭**에서 해당 날짜를 누른다.

#### 운동 & 단백질

운동 강도·종류와 그날 먹은 단백질을 한 카드에서 기록한다.
선식·계란·회사밥·단백질 음료·그릭요거트 같은 프리셋을 탭하면 g이 자동으로 합산된다.
**여러 번 탭하면 개수가 올라가고**(계란 ×2), 더블탭하면 해제된다.
프리셋에 없는 건 아래 `그 외 단백질 직접 추가 (g)` 스테퍼로 더한다.

목표는 **체중 × 계수**로 계산한다. 카드 오른쪽 아래 `목표 설정`에서 체중과 계수를 넣으면
(유지 1.2 / 근성장 1.6 / 고강도 2.0 g/kg) 그날 얼마나 채웠는지 막대로 보여준다.
**한 번만 설정하면 된다.** 체중이 바뀌었을 때만 다시 들어가면 되고, 동기화를 켜두면 폰과 맥이 같은 목표를 쓴다.

프리셋의 g 값은 대략적인 추정치다. 정확한 영양성분표가 아니라 "며칠째 충분히 먹고 있나"를
보기 위한 숫자다. 값을 바꾸고 싶으면 `index.html`의 `PROTEIN_PRESETS` 배열만 고치면 된다.

### 2. 기기 간 동기화 (Gist)

폰과 맥에서 같은 데이터를 보게 해준다. 기기마다 IndexedDB가 분리돼 있어서
동기화 없이는 기록이 절대 합쳐지지 않는다.

**켜는 법**: 통계 탭 → `☁️ 기기 간 동기화` → GitHub 토큰 붙여넣기 → 연결

토큰은 [github.com/settings/tokens](https://github.com/settings/tokens) 에서
**Tokens (classic)** → `gist` 권한만 체크해서 발급한다. 토큰 값은 발급 직후 한 번만 보이니
그 자리에서 복사해야 한다.

두 번째 기기는 토큰만 넣으면 기존 Gist를 자동으로 찾는다. Gist ID 칸은 비워두면 된다.

**동작 방식**: 앱 시작·저장·복원 시점에 원격을 읽어 로컬에 병합하고, 병합 결과를 다시 원격에 쓴다.
같은 날짜가 양쪽에 있으면 `savedAt`이 더 최근인 쪽이 이긴다.

**주의**: 삭제는 전파되지 않는다(병합 전용). 나중에 기록 삭제 기능을 넣으면
한쪽에서 지운 게 다른 쪽에서 되살아나므로 tombstone 설계가 필요하다.

### 3. 저녁 알림 (푸시)

매일 **20:00 KST**에 기록하라고 알림이 온다. 탭하면 기록 화면이 바로 열린다.

**켜는 법**: 통계 탭 → `🔔 저녁 알림` → 알림 켜기 → iOS 권한 허용

발송은 Cloudflare Worker가 한다 (`push-worker/` 참고). iOS는 웹앱이 스스로 알림을
예약할 수 없어서 외부 발송 서버가 반드시 필요하다.

**알림이 안 오면**: iOS가 구독을 만료시킨 경우다. 앱에서 알림을 껐다 켜면 복구된다.

## 백업

동기화를 켜두면 Gist가 상시 사본 역할을 하지만, **주간 JSON 백업은 계속 하는 게 좋다.**
병합 사고가 나면 Gist도 같이 오염되기 때문에, 손대지 않은 시점의 스냅샷이 따로 있어야 한다.

통계 탭 → `📦 JSON 백업` → Obsidian vault의 `backups/` 폴더에 저장.

7일 이상 백업하지 않으면 앱 실행 시 알려준다.

---

## 데이터

- 저장: IndexedDB (DB `mood-tracker`, store `entries`, key = `YYYY-MM-DD`)
- 측정 모델: Russell의 Circumplex Model (valence × arousal, 각 -3~+3)
- 내보내기: CSV / JSON
- 외부 전송은 사용자가 직접 연결한 Gist와 푸시 서버뿐. 감정 기록 자체는 Gist에만 간다.

## 개발

단일 파일 구조다. `index.html` 안에 CSS/JS가 전부 인라인으로 들어 있다.

```
index.html          # 앱 전체
service-worker.js   # 오프라인 캐싱 + 푸시 수신
manifest.json       # PWA 메타데이터
push-worker/        # 알림 발송용 Cloudflare Worker
```

`index.html`을 고치고 push하면 GitHub Pages에 1~2분 안에 반영된다.
폰에서 갱신이 안 보이면 `service-worker.js`의 `CACHE_NAME` 버전을 올려야 한다.
